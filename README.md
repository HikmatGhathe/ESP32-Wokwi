# ESP32-Wokwi

ESP32 embedded systems projects and experiments developed with C++ and simulated with Wokwi.

## Projects

### STM32C0 Mini RTOS — SysTick Context Switching

A bare-metal educational RTOS prototype for STM32C0 / ARM Cortex-M0+ demonstrating task stack initialization, TCB-based round-robin scheduling, SysTick interrupts and low-level CPU context switching.

Project: [STM32C0-Mini-RTOS](./STM32C0-Mini-RTOS)

**Technologies:** C, ARM Cortex-M0+, STM32C0, SysTick, inline ARM assembly, GPIO, stack frames, RTOS fundamentals.
